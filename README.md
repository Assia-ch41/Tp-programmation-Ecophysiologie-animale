# Analyse de la fréquence cardiaque chez l'être humain

## Introduction
La fréquence cardiaque représente le nombre de battements du cœur par minute. Elle constitue un paramètre physiologique important.

## Objectif
Étudier les variations de la fréquence cardiaque selon différents états physiologiques.

## Méthodologie
- Utilisation de données simulées.
- Analyse des données avec Python.
- Organisation des données avec Pandas.
- Calculs numériques avec NumPy.
- Réalisation de graphiques avec Matplotlib et Seaborn.

## Situations étudiées
- Au repos.
- Pendant l'activité physique.
- Après l'effort.

## Outils utilisés
Python, Jupyter Notebook, NumPy, Pandas, Matplotlib et Seaborn.
